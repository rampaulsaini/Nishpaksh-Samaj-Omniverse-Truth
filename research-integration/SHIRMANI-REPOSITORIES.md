## एक महत्वपूर्ण संपादकीय नियम

इन repositories को **एक-दूसरे की सामग्री मिटाकर** एक repository में जबरन मिलाने के बजाय पहले केंद्रीय index और cross-links से जोड़ा जा रहा है। इससे पुराने Git इतिहास, स्वतंत्र GitHub Pages और मौजूदा सामग्री सुरक्षित रहती है।

आगे आवश्यकता होने पर चयनित सामग्री को केंद्रीय repository में **स्रोत-संदर्भ और मूल repository attribution के साथ** व्यवस्थित रूप से पुनर्संयोजित किया जा सकता है।

## प्राथमिकता

1. केंद्रीय repository = canonical knowledge hub
2. Research Paper repository = research archive
3. Research Institute repository = institute/archive/media layer
4. सभी repositories में परस्पर स्पष्ट navigation
5. duplicate सामग्री को धीरे-धीरे कम करना
6. प्रत्येक बड़े दावे के लिए स्रोत/स्थिति/अनिश्चितता स्पष्ट रखना
