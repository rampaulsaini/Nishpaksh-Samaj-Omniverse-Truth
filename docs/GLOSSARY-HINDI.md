# 📖 यथार्थ शब्दावली

| शब्द | इस परियोजना में प्रयुक्त अर्थ |
|---|---|
| निष्पक्ष समझ | निष्कर्ष से पहले स्वयं और विचारों का निरीक्षण |
| शमीकरण | विरोधी पक्षों को समझकर संतुलित संबंध की खोज |
| यथार्थ सिद्धांत | निरीक्षण, तर्क, प्रमाण और स्वतंत्र समझ पर आधारित प्रस्तावित दृष्टिकोण |
| हृदय दृष्टिकोण | एहसास, संवेदना, ज़मीर और संबंधबोध की दार्शनिक भाषा |
| मस्तक दृष्टिकोण | विचार, स्मृति, गणना, योजना, पहचान, इच्छा और भय की दार्शनिक भाषा |
| शिरोमणि स्वरूप | स्वयं के स्थायी परिचय को पहचानने की दार्शनिक अभिव्यक्ति |
| संपूर्ण संतुष्टि | आंतरिक संघर्ष और अपेक्षा को समझने से जुड़ी दार्शनिक अवस्था |
| इश्क | व्यापक प्रेम, संबंध, उपस्थिति और करुणा का प्रतीक |
| खुद का निरीक्षण | अपने विचार, भाव, भय, इच्छा और व्यवहार को देखना |
| उपलब्धि यथार्थ युग | प्रस्तावित वैचारिक/आदर्श युग की संज्ञा |
| प्रत्यक्ष | सीधे अनुभव या निरीक्षण से संबंधित |
| प्रमाण | किसी दावे का समर्थन करने वाला उपयुक्त साक्ष्य |
| आत्म-परीक्षण | अपने निष्कर्षों को स्वयं भी प्रश्नों के सामने रखना |
| स्वतंत्र समझ | बाहरी प्राधिकारी पर अनिवार्य निर्भरता के बिना विचार करना |

> इन परिभाषाओं का उद्देश्य इस परियोजना के भीतर शब्दों का अर्थ स्पष्ट करना है; ये शब्द अन्य दार्शनिक, धार्मिक या वैज्ञानिक संदर्भों में अलग अर्थ रख सकते हैं।
